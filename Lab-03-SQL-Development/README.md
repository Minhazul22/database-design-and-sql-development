# Lab 3 – SQL Development

## Focus
Implementing relational schemas and writing SQL queries for different database scenarios.

## Exercises covered
- Student information system: CREATE TABLE statements, data types, constraints, sample INSERT statements, and queries about programs, prerequisites, successful credit points, and student deletion.
- Shipping company: date filtering, pattern matching, aggregation per ship, identifying unused base harbors, and grouped counts.
- COMPANY example: joins, self-joins, aggregation, backup-table creation, foreign-key delete behaviour, and department-level salary analysis.
- Cinema and weather databases: formulating query requirements in both relational algebra and SQL.

## Portfolio materials
Add executable SQL scripts, schema/setup notes, synthetic sample data, and concise explanations of representative queries. Keep destructive statements clearly marked and use a test database.
