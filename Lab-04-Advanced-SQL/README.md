# Lab 4 – Advanced SQL

## Focus
Transaction management, database views, and transaction visibility.

## Exercises covered
- Chemistry database: transactions that insert related records, rollback on failure, and record changes in a changelog.
- Researcher details view: joining researcher and lab information and testing INSERT, DELETE, and UPDATE behaviour.
- Geography database: filtering and sorting data, inserting a country and language, checking inserted data, and creating a view for each country's largest city and highest mountain.
- COMPANY views: project summaries, grouped employee and working-hour information, and view modification behaviour with WITH CHECK OPTION.
- Transactions: testing table visibility, uncommitted inserts, COMMIT, UPDATE, and ROLLBACK across two database sessions.

## Portfolio materials
Add the SQL scripts, setup instructions, and carefully labelled outputs or screenshots that demonstrate the behaviour. Document the order of operations for the two-session experiment, because timing and commit state affect what each session can see.
