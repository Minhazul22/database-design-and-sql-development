# Lab 2 – Relational Design

## Focus
Mapping ER models to relational schemas and reasoning about relational structure.

## Exercises covered
- Relational schemas for student information and hotel scenarios, including identifying keys and modelling stand-in relationships.
- Functional dependencies, primary-key identification, decomposition into 2NF and 3NF, and ERD creation from a 3NF schema.
- Relational algebra queries over a chess-player and game schema.
- Relational modelling exercises for favorite books and laboratory organization.
- Candidate-key identification and normal-form analysis for shop and general relations.

## Portfolio materials
Add relational schemas, key annotations, functional-dependency analysis, normalization walkthroughs, and relational algebra solutions here. Explain each decomposition and preserve the distinction between candidate keys, primary keys, and foreign keys.
