# Lab 1 – Database Modelling

## Focus
Conceptual database modelling using Entity-Relationship diagrams.

## Exercises covered
- Student information system: requirements analysis, Chen notation, MC notation, semantic integrity requirements, and additional attribute types.
- Movie database: translating MC notation to Chen notation, choosing attributes and keys, and reasoning about model constraints.
- Bar owner and zoo scenarios: identifying entities, relationships, attributes, and keys.
- Laboratory organization and cooking club scenarios: modelling team membership, leadership, lab sections, experiments, dinners, attendance, and recipes.
